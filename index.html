How it works

Three tools, one smooth result

1

Spline

Live 3D scenes render in the page with drag to rotate. Each template includes a fallback illustration so the page is never blank.

2

Lenis

Buttery smooth scrolling ties the whole page together and feeds scroll driven animation.

3

GSAP

ScrollTrigger powers reveals, scrub motion, and counters. All calls are guarded so pages still work if a CDN fails.

Copy guide

From template to live site in four moves

  1. Preview locally with one command, then open the hub in your browser.
  2. Copy one template folder and rename it for your project.
  3. Swap the Spline scene URL in that folder's index file.
  4. Edit the copy, colors, and prices, then deploy the folder.

Run the hub

cd spline-3d-templates
python3 -m http.server 8000

Use a template

cp -r template-04-shop-stage my-shop
# open my-shop/index.html, swap the
# spline-viewer url, edit and ship

To swap the 3D scene, change one attribute: the url on the spline viewer tag.
